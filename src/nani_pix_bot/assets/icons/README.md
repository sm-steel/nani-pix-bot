# Card icons

Small colour icons drawn on generated cards (the profile card's stats chips,
the season card's date pill), since the card fonts have no emoji. One PNG per
icon key, 128x128 RGBA.

| File | Emoji | Source |
|---|---|---|
| `medal.png` | 🏅 U+1F3C5 | `2D/png/128/emoji_u1f3c5.png` |
| `gift.png` | 🎁 U+1F381 | `2D/png/128/emoji_u1f381.png` |
| `calendar.png` | 🗓 U+1F5D3 | `2D/png/128/emoji_u1f5d3.png` |

Source: [Noto Emoji](https://github.com/googlefonts/noto-emoji), tag
`v2026-09-24-unicode18_0`. The images are licensed under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)
(© Google LLC); unchanged.

`ofuda.png` and `omamori.png` are different: 512x512 RGBA art of the two Halloween
charms (Ofuda, Omamori), generated for Nani Pix (MIT, like the rest of her art), drawn
on the consumable preview card (`services/cosmetics/consumable_card.py`).
