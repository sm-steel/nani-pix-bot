# Card icons

Small colour icons drawn on generated cards (the profile card's stats line),
since the card fonts have no emoji. One PNG per icon key, 128x128 RGBA.

| File | Emoji | Source |
|---|---|---|
| `medal.png` | 🏅 U+1F3C5 | `2D/png/128/emoji_u1f3c5.png` |
| `gift.png` | 🎁 U+1F381 | `2D/png/128/emoji_u1f381.png` |
