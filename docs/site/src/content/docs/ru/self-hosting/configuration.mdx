Все настройки хранятся в файле `.env` рядом с `docker-compose.yml`. Начните с
примера — в его комментариях объяснён каждый параметр:

```sh
cp .env.example .env
```

## Обязательные

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather. |
| `GROUP_CHAT_ID` | id вашей группы (отрицательное число). |
| `GAME_TOPIC_ID` | id темы, в которой идёт игра. |
| `DATABASE_URL` | Как бот подключается к MariaDB. Пароль в нём должен совпадать с `MARIADB_PASSWORD`. |
| `MARIADB_ROOT_PASSWORD`, `MARIADB_DATABASE`, `MARIADB_USER`, `MARIADB_PASSWORD` | Настройки самой базы. Пароли придумайте свои. |

Как узнать id группы и темы — в разделе [Свой бот](/nani-pix-bot/ru/self-hosting/).

Кто считается админом, здесь не настраивается: бот спрашивает у Telegram, поэтому
админские команды доступны админам и владельцу самой группы. В `.env.example` есть
строка `ADMIN_USER_IDS=`, но бот её не читает, так что оставьте её пустой.

## Необязательные

| Параметр | Что делает |
|---|---|
| `TMDB_READ_ACCESS_TOKEN` | Включает TMDB как способ искать аниме и скриншоты. Нужен **API Read Access Token** из настроек API вашего аккаунта TMDB, а не старый «API Key». Без него TMDB всё равно есть в списке, но любой поиск и скриншот через TMDB заканчивается сообщением, что сервис, похоже, недоступен, так что задайте токен или предупредите игроков. |
| `TELEGRAM_PROXY_URL` | Пускает трафик бота через HTTP-прокси — для серверов, откуда Telegram недоступен напрямую. Запросы к TMDB, Tenrai и MyAnimeList тоже идут через него. |
| `MAL_CLIENT_ID`, `MAL_CLIENT_SECRET`, `MAL_REDIRECT_URI`, `MAL_TOKEN_ENCRYPTION_KEY` | Привязка MyAnimeList. Либо все четыре, либо ни одного. См. [Привязка MyAnimeList](/nani-pix-bot/ru/self-hosting/myanimelist/). |
| `LOG_LEVEL` | Насколько подробно бот пишет логи: по умолчанию `INFO`, для подробностей — `DEBUG`. |
| `LOG_FORMAT` | По умолчанию `text`. `json` пишет по одному JSON-объекту на строку, с номером игры, пользователем, чатом и версией бота в отдельных полях, — для сборщиков логов вроде Loki или Vector. С любым другим значением бот не запустится и сообщит об ошибке. |
