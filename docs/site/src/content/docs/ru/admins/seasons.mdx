Сезон — это событие на ограниченное время со своими правилами и своим зачётом.
Полная страница для игроков появится позже; эта — о том, как сезон запланировать.

`/season` работает в личных сообщениях с ботом и только для админов группы.

## Ваш часовой пояс

Даты вводятся в **вашем часовом поясе** — том, что указан через `/timezone` (см.
[Автоматические раунды и тихие часы](/nani-pix-bot/ru/admins/schedule/)). Если пояс не указан,
`/season` сначала попросит его задать. Во всех ответах даты показываются в этом поясе.

## Команды

| Команда | Что делает |
|---|---|
| `/season` | Показывает текущий сезон, прошедшие и те, что ещё можно запланировать |
| `/season schedule <сезон> <ГГГГ-ММ-ДД> <ЧЧ:ММ> <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Планирует сезон: его id, затем начало, затем конец |
| `/season start <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Переносит начало ещё не начавшегося сезона |
| `/season end <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Переносит конец |
| `/season end now` | Завершает идущий сезон прямо сейчас |
| `/season cancel` | Отменяет ещё не начавшийся сезон |

Например:

```
/season schedule sakura_1 2026-11-20 18:00 2026-11-30 18:00
```

В состоянии также видно, кто запланировал каждый сезон.

## Правила

- Одновременно может быть запланирован или идти только один сезон.
- Каждый сезон проводится один раз. Начавшийся сезон больше не предлагается;
  отменённый до начала можно запланировать снова.
- Конец должен быть позже начала и в будущем.
- Начало можно сдвинуть, а сезон отменить только до его старта.

## Что видит группа

Бот публикует в группе анонс, когда сезон запланирован (и повторно, если даты
сдвинулись), сообщение о старте и сообщение о конце. Если сезон завершён, пока
ещё идут игры, он закончится, когда эти игры завершатся.
