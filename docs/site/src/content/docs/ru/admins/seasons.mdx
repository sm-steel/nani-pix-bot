Сезон — это событие на ограниченное время со своими правилами и своим зачётом.
Первым был [Сезон сакуры](/nani-pix-bot/ru/seasons/sakura-season/) (`sakura_1`); хэллоуинский —
[Ночь ёкаев](/nani-pix-bot/ru/seasons/yokai-night/) (`yokai_1`), рассчитанная примерно на две
недели вокруг 31 октября. Эта страница — о том, как сезоны запланировать.

`/season` работает в личных сообщениях с Nani Pix и только для админов группы.

## Ваш часовой пояс

Даты вводятся в **вашем часовом поясе** — том, что указан через `/timezone` (см.
[Автоматические раунды и тихие часы](/nani-pix-bot/ru/admins/schedule/)). Если пояс не указан,
`/season` сначала попросит его задать. Во всех ответах даты показываются в этом поясе.

## Команды

| Команда | Что делает |
|---|---|
| `/season` | Показывает текущий сезон, прошедшие и те, что ещё можно запланировать |
| `/season schedule <сезон> <ГГГГ-ММ-ДД> <ЧЧ:ММ> <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Планирует сезон: его id, затем начало, затем конец |
| `/season start <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Переносит начало ещё не начавшегося сезона |
| `/season end <ГГГГ-ММ-ДД> <ЧЧ:ММ>` | Переносит конец |
| `/season end now` | Завершает идущий сезон прямо сейчас |
| `/season cancel` | Отменяет ещё не начавшийся сезон |

Например:

```
/season schedule yokai_1 2026-10-28 06:00 2026-11-12 06:00
```

В состоянии также видно, кто запланировал каждый сезон.

## Правила

- Одновременно может быть запланирован или идти только один сезон.
- Каждый сезон проводится один раз. Начавшийся сезон больше не предлагается;
  отменённый до начала можно запланировать снова.
- Конец должен быть позже начала и в будущем.
- Начало можно сдвинуть, а сезон отменить только до его старта.
- Особый день сезона наступает, только если он попадает в даты сезона.
  [Ночной парад](/nani-pix-bot/ru/seasons/haunted-rounds/#ночной-парад) Ночи ёкаев — это
  31 октября по часовому поясу группы: тому, что задан для [тихих часов](/nani-pix-bot/ru/admins/schedule/#тихие-часы),
  или UTC, если он не задан, а не по вашему `/timezone`. Планируйте сезон с захватом всего этого дня.

## Выдача предмета

`/grantitem @username <id предмета>` (в личке, для админов группы) выдаёт игроку сезонный
косметический предмет, например `/grantitem @bob sakura_1/name_flair.blossom`. Id предмета —
это id сезона, косая черта и ключ предмета. Без `@username` (`/grantitem <id предмета>`) она покажет меню игроков на выбор. Nani Pix назовёт выданный предмет, либо ответит, что
он у игрока уже есть, либо что не знает такого игрока или предмета.

## Что видит группа

Nani Pix публикует в группе анонс, когда сезон запланирован (и повторно, если даты
сдвинулись; правки дат, сделанные до публикации анонса, попадают в этот же пост), сообщение о старте и
сообщение о конце. Если сезон завершён, пока ещё идут игры, он закончится, когда эти игры
завершатся.

с градиентом и плашка 🗓 с датами. Вот пост о старте Ночи ёкаев:

## Сезонные монеты в конце

Когда сезон заканчивается, оставшиеся у игроков сезонные монеты 🪙 превращаются в пиксели 💠
по курсу сезона (обычно 2 🪙 за 1 💠; лишняя монета пропадает), а все балансы монет
обнуляются. В итоговом посте сказано, у скольких игроков монеты стали каким количеством 💠
и по какому курсу. См. [Сезонные монеты и пропуск](/nani-pix-bot/ru/seasons/season-pass/).
