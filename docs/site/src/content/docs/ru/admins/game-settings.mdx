## Этапы пикселизации

У каждого из пяти этапов две настройки: **ширина** запикселенной картинки (в
блоках; чем меньше блоков, тем сложнее) и сколько **неверных попыток** этап
допускает до перехода к следующему. По умолчанию:

<table>
  <thead><tr><th>Этап</th><th>Ширина</th><th>Неверных попыток</th></tr></thead>
  <tbody>{stages.map((s) => <tr><td>{s.stage}</td><td>{s.width}</td><td>{s.wrongGuessLimit}</td></tr>)}</tbody>
</table>

- `/stageconfig` показывает текущие настройки.
- `/setstageconfig` задаёт все пять этапов сразу — парами `ширина:попытки` от
  первого этапа к пятому. Значения по умолчанию выглядели бы так:
  <code>/setstageconfig {example}</code>
- `/setstage <этап 1-5> <ширина> <попытки>` меняет один этап, например
  `/setstage 1 48 1` для ещё более сложного начала.

После изменения бот отвечает обновлённой таблицей, а затем для каждого изменённого
этапа присылает две картинки-примера с новой шириной. Под первой — название этапа,
ширина и число неверных попыток:

<TelegramChat label="Пример: изменение первого этапа">
  <TgMessage out>/setstage 1 48 1</TgMessage>
  <TgMessage from="nani-pix-bot" image={stage1}>STAGE_1 — 48px, разрешено 1 неверных попыток</TgMessage>
</TelegramChat>

**Пока раунд готовится, идёт или по нему открыто голосование, менять этапы
нельзя.** Бот откажет и сразу предложит те же кнопки, что и `/stop`. Когда раунд
остановлен, отправьте команду ещё раз.

<TelegramChat label="Пример: изменение этапа во время раунда">
  <TgMessage out>/setstage 1 48 1</TgMessage>
  <TgMessage from="nani-pix-bot" buttons={[['🛑 Да, остановить'], ['🔎 Остановить и раскрыть'], ['❌ Нет, продолжить']]}>
    Сейчас идёт игра — сначала остановите её, чтобы изменить настройки этапов.
  </TgMessage>
</TelegramChat>

Кнопка **🔎 Остановить и раскрыть** появляется, только пока раунд идёт; если раунд
ещё готовится, выбор — просто да или нет.

То, как выбирается цвет каждого блока, — не настройка админа. Его выбирает тот,
кто начинает раунд, в превью, для каждого раунда отдельно (см.
[Как начать раунд](/nani-pix-bot/ru/players/starting-a-round/#превью)). Картинки-примеры
выше используют вариант по умолчанию.

У хардмода свои фиксированные правила, эти настройки на него не влияют.

## Частичные совпадения

Если в неверной догадке есть целые слова из ответа, бот их раскрывает (см.
[Догадки](/nani-pix-bot/ru/players/guessing/#частично-верно)). Но только когда в
совпавших словах набирается достаточно букв.

- `/partialmatch` показывает текущую настройку (по умолчанию 4 буквы).
- `/partialmatch <буквы>` меняет её. `/partialmatch 0` отключает частичные
  раскрытия.

<TelegramChat label="Пример: повышение порога частичных совпадений">
  <TgMessage out>/partialmatch 5</TgMessage>
  <TgMessage from="nani-pix-bot">✅ Частичные совпадения теперь раскрываются от 5 совпавших букв (0 = выкл.).</TgMessage>
</TelegramChat>

## Награды и цены в пикселях

Любую сумму в пикселях — от награды за неверную догадку до цены каждой подсказки
и `/sharpen` — можно изменить:

- `/pixelconfig` показывает все настройки в виде `ключ — значение — описание`,
  например `clue_tile — 100 — Подсказка: один тайл без пикселизации`.
- `/pixelconfig <ключ> <значение>` меняет одну. Значение — целое число.

<TelegramChat label="Пример: подсказка-фрагмент становится дешевле">
  <TgMessage out>/pixelconfig clue_tile 80</TgMessage>
  <TgMessage from="nani-pix-bot">✅ clue_tile = 80.</TgMessage>
</TelegramChat>

Не каждое значение подходит для каждого ключа:

- **Награду** можно сделать равной 0 — так она отключается.
- **Цена** должна быть не меньше 1. На меньшее значение бот ответит «Цены —
  минимум 1 💠.»
- `clue_cashback_percent` — процент от 0 до 100. На значение больше 100 бот
  ответит «Проценты должны быть от 0 до 100.»
- `clue_screenshot_step` может быть 0 — тогда каждый доп. скриншот стоит одинаково.

В отличие от настроек этапов, эти можно менять и во время раунда. Изменение
действует только на то, что происходит после него.

### Все ключи

**Награды** (0 отключает награду):

| Ключ | По умолчанию | Что это |
|---|---|---|
| `starting_balance` | 50 | Стартовый баланс нового игрока |
| `wrong_guess` | 2 | За неверную догадку |
| `wrong_guess_cap` | 10 | Максимум за неверные догадки на игрока за игру |
| `first_guess` | 5 | Первая догадка в игре |
| `win_stage_1` | 40 | Верный ответ на этапе 1 |
| `win_stage_2` | 30 | Верный ответ на этапе 2 |
| `win_stage_3` | 25 | Верный ответ на этапе 3 |
| `win_stage_4` | 20 | Верный ответ на этапе 4 |
| `win_stage_5` | 15 | Верный ответ на этапе 5 |
| `setter` | 15 | Ведущему, если его игру отгадали на этапах 2–4 |
| `prompt_turn` | 10 | Ведущему за старт в течение часа после получения хода |
| `disputed_win_bonus` | 30 | Бонус победителю, выбранному голосованием группы или через `/setwinner` |
| `achievement_bronze` | 25 | Награда за бронзовое достижение |
| `achievement_silver` | 75 | Награда за серебряное достижение |
| `achievement_gold` | 200 | Награда за золотое достижение |
| `achievement_platinum` | 500 | Награда за платиновое достижение |

**Цены** (не меньше 1):

| Ключ | По умолчанию | Что это |
|---|---|---|
| `clue_last_letter` | 60 | Подсказка: последняя буква |
| `clue_first_letter` | 100 | Подсказка: первая буква |
| `clue_title_shape` | 120 | Подсказка: форма названия |
| `clue_screenshot` | 150 | Подсказка: первый доп. скриншот |
| `clue_tile` | 100 | Подсказка: один тайл без пикселизации |
| `sharpen` | 250 | Прояснить картинку на этап (`/sharpen`) |

**Прочее:**

| Ключ | По умолчанию | Что это |
|---|---|---|
| `clue_screenshot_step` | 75 | Подсказка: надбавка за каждый следующий доп. скриншот |
| `clue_cashback_percent` | 50 | % трат на подсказки, возвращаемый покупателям, если раунд хардмода не разгадан (0–100) |
