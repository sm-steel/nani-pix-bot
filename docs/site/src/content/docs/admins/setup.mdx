This section is for the **admins and owner** of the group Nani Pix plays in. Every
admin command is sent to her in a **private message**, and she checks with
Telegram that you really are an admin of the group each time.

Hosting your own copy of Nani Pix? Start with [Self-hosting](/nani-pix-bot/self-hosting/);
this page covers the group side.

## The group and its game topic

1. The group must be a **supergroup with Topics turned on** (Group settings →
   Topics). Nani Pix plays in one specific topic, not in the main chat.
2. Add the bot to the group and make it an **admin with the "Pin messages"
   permission**. Nani Pix keeps the current round's picture pinned in the topic.
   Without that permission everything still works, just without the pin.
3. Pick the topic the game is played in. Whoever hosts Nani Pix configures which
   topic that is.

Players need to be **members of the group** for most of what Nani Pix does for
them. Someone who isn't a member can't:

- start a round (by sending a screenshot or with `/newgame`),
- open the clue shop or buy clues, including from the 🛒 button under a stage,
- see `/achievements`, `/history`, `/title`, or `/leaderboard` and `/standings` in
  a private message,
- follow a link that opens achievements or standings in a private chat with
  Nani Pix.

`/leaderboard` and `/standings` sent in the game topic itself work for anyone who
can read it. Players should also send Nani Pix `/start` once, so she can message
them privately (for clues, reminders and the shop).

## Language

Nani Pix speaks **English or Russian**, the same language for the whole group: the
game topic, private messages and her command menu. To switch, send
`/language` to her and tap a language. The two buttons are always labelled in
their own language.

<TelegramChat label="Example: switching Nani Pix from Russian to English">
  <TgMessage out>/language</TgMessage>
  <TgMessage from="Nani Pix" buttons={[['🇷🇺 Русский'], ['🇬🇧 English']]}>Выберите язык Nani Pix:</TgMessage>
  <TgMessage from="Nani Pix">Language set to English.</TgMessage>
</TelegramChat>

The prompt is in Nani Pix's current language, and after the tap it turns into the
confirmation, in the new one. Only a group admin or the owner can change the
language; anyone else gets "Only a group admin can change my language."
The other admin commands answer non-admins with "Admins only."
