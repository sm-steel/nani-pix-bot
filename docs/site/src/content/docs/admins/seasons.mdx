A season is a limited-time event with its own rules and standings. The first one is
[Sakura Season](/nani-pix-bot/seasons/sakura-season/) (`sakura_1`), meant to run for about
ten days; this page is for scheduling it.

`/season` works in a DM with Nani Pix, for group admins only.

## Your time zone

Dates are typed in **your own time zone**, the one you set with `/timezone` (see
[Automatic rounds and quiet hours](/nani-pix-bot/admins/schedule/)). Without one, `/season`
asks you to set it first. Every reply shows the dates back in that zone.

## Commands

| Command | What it does |
|---|---|
| `/season` | Shows the current season, the seasons held before it and the ones you can still schedule |
| `/season schedule <run> <YYYY-MM-DD> <HH:MM> <YYYY-MM-DD> <HH:MM>` | Schedules a season: its id, then start, then end |
| `/season start <YYYY-MM-DD> <HH:MM>` | Moves the start of a season that hasn't started yet |
| `/season end <YYYY-MM-DD> <HH:MM>` | Moves the end |
| `/season end now` | Ends a running season right away |
| `/season cancel` | Cancels a season that hasn't started yet |

For example:

```
/season schedule sakura_1 2026-11-20 18:00 2026-11-30 18:00
```

The status view also shows who scheduled each season.

## Rules

- Only one season can be scheduled or running at a time.
- Each run can be held once. A run that has started is never offered again; one
  that was cancelled before starting can be scheduled again.
- The end has to come after the start, and in the future.
- The start can only be moved before the season begins, and so can cancelling.

## Giving a cosmetic

`/grantitem @username <item id>` (DM, group admins) gives a player a season cosmetic, for
example `/grantitem @bob sakura_1/name_flair.blossom`. The item id is the run id, a slash,
then the item's key. Leave out the `@username` (`/grantitem <item id>`) and she shows a menu of players to choose from. Nani Pix names the item she gave, or says the player already has it, or
that she doesn't know the player or the item.

## What the group sees

Nani Pix posts a teaser to the group when a season is scheduled (and again if its
dates move; date edits made before the teaser is posted share that one post), an announcement when it starts and another when it ends. A season
that is ended while games are still running finishes once those games are done.

These posts are cards over the season's key visual: a ribbon headline, the season's stamp,
the name in a gradient and a 🗓 pill with the dates. This is Sakura Season's start post:

## Season Coins at the end

When a season ends, every player's leftover Season Coins 🪙 are turned into pixels 💠 at
the run's rate (normally 2 🪙 for 1 💠; a leftover odd coin is dropped) and every coin
balance is emptied. The end post says how many players' coins became how much 💠, and the
rate. See [Season Coins and the Season Pass](/nani-pix-bot/seasons/season-pass/).
