## Good to know

- **`/help` in the game topic is answered privately**, so the topic stays clean.
  Nani Pix can only message you if you've started a chat with her first; if you
  haven't, she asks you to in the topic:

<TelegramChat label="Example: /help before you've messaged Nani Pix">
  <TgMessage out>/help</TgMessage>
  <TgMessage from="Nani Pix">Please message me privately first — @your_bot — then try /help again.</TgMessage>
</TelegramChat>

- **`/version`** shows which version of Nani Pix your group is running and what
  changed in it, with buttons to page back through earlier releases. The same
  notes are in [What's new](/nani-pix-bot/whats-new/).

- **`/hex`, `/hexes`, `/omikuji` and `/candles`** only work during a season that has
  them, such as [Yōkai Night](/nani-pix-bot/seasons/yokai-night/): see
  [Hexes](/nani-pix-bot/seasons/hexes/), [Omikuji and charms](/nani-pix-bot/seasons/omikuji-and-charms/)
  and [100 Candles](/nani-pix-bot/seasons/hundred-candles/). `/inventory` lists your clue
  tokens and charms at any time.
