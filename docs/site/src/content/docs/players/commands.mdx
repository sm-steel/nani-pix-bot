## Good to know

- **`/help` in the game topic is answered privately**, so the topic stays clean.
  The bot can only message you if you've started a chat with it first; if you
  haven't, it asks you to in the topic:

<TelegramChat label="Example: /help before you've messaged the bot">
  <TgMessage out>/help</TgMessage>
  <TgMessage from="nani-pix-bot">Please message me privately first — @your_bot — then try /help again.</TgMessage>
</TelegramChat>

- **`/version`** shows which version of the bot your group is running and what
  changed in it, with buttons to page back through earlier releases. The same
  notes are in [What's new](/nani-pix-bot/whats-new/).
