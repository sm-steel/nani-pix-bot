# Card background prompts

Output size: generate at 2400x1260 (about 1.905:1). If the generator only offers standard ratios, use **16:9 (for example 2560x1440), then crop to 1.905:1 by trimming the top and bottom equally** (about 4% off each edge, 1440 -> 1344). Keep the left third's glow and the right-side calm area intact. Downscale if needed; the renderer cover-crops to 1200x630 anyway.

## Shared style guide (already included in every prompt below)

- Soft painterly anime background art (Makoto Shinkai / Ghibli-like environment painting), cinematic lighting, gentle depth of field, clean gradients. Original anime characters only at the frame edges (unlock: far right; podium: far left and right), small, back-turned or in profile; never existing franchise characters.
- One cohesive set: deep blue-violet and near-black shadows (matching the #16181F card base), with ONE accent colour per slot tied to the rarity or podium colour so the border and avatar ring harmonise.
- Atmospheric, not busy: large soft areas, bokeh, haze, distant silhouettes. Detail only at the edges or far away.
- Unlock slots: left third = soft glow for the avatar, right ~60% = calm, dark, low-detail. Podium slots: centre band, top title strip and area under the avatars calm; interest at the left/right edges and in background depth.
- Wide cinematic framing, 1.9:1, no text of any kind, family-friendly.

**Shared negative prompt** (already included in every Negative prompt below):
`characters in the centre or the left third, characters overlapping the avatar area, crowds, close-up faces, existing anime characters, famous characters, text, letters, numbers, logo, watermark, signature, UI, frame, border, busy details, clutter, high contrast noise, photorealistic, copyrighted character, franchise imagery, nsfw, gore`

Colour keys: Bronze #CD7F32, Silver #C0C7D4, Gold #F0BE28, Platinum #6EE1EB. Podium colours follow the same family (week = bronze-ish warm, month = silver-blue, year = gold).

## How to add them

1. Generate each image at 2400x1260 (or 16:9 and crop as described above). Use each variant's Prompt and Negative prompt as is — the shared style and negatives are already merged in.
2. Save the files into the bot repo as `src/nani_pix_bot/assets/backgrounds/<slot>/<n>.png`, for example `src/nani_pix_bot/assets/backgrounds/unlock/gold/1.png` or `.../podium/year/3.png`. Numbering starts at 1 with no gaps.
3. Any PNG or JPG is fine; the renderer cover-crops it to 1200x630 and lays the dark overlay on top. A missing slot falls back to the flat dark style, so slots can be added gradually.
4. Check each image under the overlay at 1200x630: text must stay readable, and nothing bright or detailed should sit inside the avatar circles (unlock: centre x=225, y=315, 300 px; podium: #1 at centre y=300, #2 x=300, #3 x=900). Regenerate if it does.

## How the current set was prepared

The shipped images were generated as 1024x1024 JPGs, then converted to PNG and
cropped to the card ratio (1200:630, so 1024x538). By default the crop removed
3/4 of the excess from the top and 1/4 from the bottom. Three images needed a
custom crop so their subject stayed in frame:

| File | Kept rows of the 1024 px original | Why |
|---|---|---|
| `unlock/bronze/2.png` | 135–673 | the boy's head starts at ~155 px |
| `unlock/gold/2.png` | 45–583 | the girl's head starts at ~65 px |
| `podium/year/3.png` | 486–1024 | the lanterns and people fill the bottom |

When adding a new image, check that heads and the main subject survive the crop.
The renderer cover-crops anything that isn't already 1200:630.
